🧁 Doce Encanto Confeitaria

Uma aplicação web interativa desenvolvida para a Doce Encanto Confeitaria, apresentando o catálogo de produtos e um formulário de encomendas reativo.

📐 Arquitetura do Projeto

A arquitetura do projeto foi planejada focado na separação clara de responsabilidades, garantindo modularidade e fácil manutenção. Os comportamentos e interações são conectados diretamente no arquivo principal (index.html).

Trabalho-Maria/
└── doce-encanto/
    ├── index.html       # Estrutura principal da página
    ├── style.css        # Estilização com Layout Flexbox e Grid
    ├── script.js        # Lógica de interações e scripts auxiliares
    └── form.js          # Componente reativo de formulário em React


🛠️ Tecnologias Utilizadas

Front-End:

    HTML5 (index.html): Estruturação semântica e acessível da página.

    CSS3 (style.css): Estilização responsiva construída com Flexbox e CSS Grid.

    JavaScript ES6+ (script.js): Manipulação do DOM e lógica da interface.

    React (form.js)

🚀 Funcionalidades

    Menu Responsivo: Navegação otimizada para dispositivos móveis e desktops.

    Catálogo de Produtos: Exibição dos doces e produtos disponíveis da confeitaria.

    Formulário Dinâmico de Encomendas:

    Validação de campos obrigatórios (Nome, Produto, Quantidade, Data de Retirada).


💻 Como Executar o Projeto

    Clonar o Repositório:

        git clone https://github.com/mreduardasilva79-sketch/doce-encanto.git


    Acessar a Pasta do Projeto:

        cd doce-encanto


    Abrir a Aplicação:

        Basta abrir o arquivo index.html em qualquer navegador web de sua preferência.

        Caso utilize o VS Code, pode abrir utilizando a extensão Live Server.
